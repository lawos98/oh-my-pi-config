# Penpot connection in this OMP setup

Use the effective global `penpot` entry in `~/.omp/agent/mcp.json`: tokenless HTTP transport at `http://localhost:9001/mcp/stream`, timeout 120000 ms, server instructions disabled. Never print whole configuration or unrelated server secrets. Start a fresh OMP process after MCP/extension configuration changes; do not assume the current tool inventory refreshed. Open the authorized native file and connect its MCP browser plugin through supported UI when needed. Inspect actual file/page IDs and object access read-only before edits. Use the current project's operating instructions rather than a legacy product-specific container recipe.

Separate checks: server reachable; tools discovered; browser connected; expected file/page active; edits saved. API-documentation success proves only that documentation is available. Do not install another server or change host exposure to fix a disconnected browser. Ask for the missing browser connection only after read-only diagnosis.

Current official guidance: https://help.penpot.app/mcp/ (accessed 2026-10-01). The old repository is archived; current source is https://github.com/penpot/penpot/tree/develop/mcp. The archived upstream setup guide is retained only for provenance, not operational use.
