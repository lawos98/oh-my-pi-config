Accepted does not mean completed

Read left to right: acknowledgement precedes asynchronous processing.

  1. 1. Submit requestThe client sends a job to the API.
  2. 2. AcknowledgeThe API returns an accepted response and a job identifier.
  3. 3. Complete laterThe worker finishes; the client reads job status.

Assumption / illustrative example: This is a conceptual sequence, not a verified description of a repository or a timing measurement. All three steps remain visible without motion.
