# Local references, templates and assets

No bundled template library is required. Use the project's existing native libraries and assets first. For a separately authorized external reference, record its source URL, license, reuse purpose and actual import status; do not assume an installed catalog or previously imported IDs.

Select task-relevant templates for structure, tokens/typography/variants, flows/prototypes, responsive layout, accessibility or icons. They are references, not accepted product designs. Recorded import IDs may belong to a historical instance: confirm actual file/page access, fonts and dependencies in the current authorized instance before reuse. Do not claim imports or rendered/interaction verification from catalog records alone, and avoid duplicate copies.

Preserve attribution, source links, license links and a statement of modifications for adaptations. Check each downloaded archive's license and retain specific/embedded license and third-party icon/font notices; a blanket archive license does not override them. Avoid redistributing fonts or competitor artwork whose reuse rights are not established. Use proprietary interfaces as observed inspiration only.

For additional native imports, use Penpot's dashboard import into a separate reference project/file, then inspect the imported file and required libraries/fonts. Public `Use in Penpot.app` links target the hosted service; for this workstation prefer the downloaded file in the local instance. Agent copy/paste should preserve component structure and map styles to the chosen project system rather than import an unrelated brand wholesale.

Optional plugin registrations are not proof of browser availability. Inspect current capabilities before relying on them; do not install or register plugins as a side effect. Use authorized existing icons and native operations where available.

For original artwork, confirm a configured image tool, use fictional non-sensitive inputs, and specify palette, camera/projection, scale, edge treatment, lighting and export background. Keep interface text outside the image. Prefer a coherent asset sheet or matched set over unrelated one-off generations. Do not claim an image generator is installed/configured just because a design skill mentions it.
