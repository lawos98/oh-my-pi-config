## Changes

The OMP adaptation narrows the broad documentation framework to hands-on tutorial/onboarding authoring; preserves observable checkpoints, recovery and repeatability; replaces compulsory execution and repair loops with OMP approval and bounded checks; distinguishes observed output from contract-derived examples; and excludes fictional example applications, upstream Python helpers, installers and site scaffolding.
