- scripts/package_skill.py: reject symbolic/hard links and non-regular inputs,

- scripts/run_eval.py: opt-in before model subprocesses or command-file writes,
  safe skill/project inputs, exclusive command files, complete CLI arguments.
- scripts/improve_description.py: explicit provider subprocess opt-in.
- scripts/run_loop.py: propagate consent, validate inputs and use new, safe
  report/results paths rather than overwriting existing outputs.
- scripts/generate_report.py: remove remote fonts and escape report metadata.
- eval-viewer/generate_review.py: restrict files to the workspace, escape
  embedded script data, restrict feedback Host/Origin and payloads, use atomic
  owner-only feedback files, bind loopback and never kill unrelated processes.
- eval-viewer/viewer.html: remove remote browser assets, escape dynamic values,
  use passive previews and retain downloads for SVG/PDF/spreadsheet outputs.
- tests/test_safety.py: local regression coverage for packaging boundaries,
  same-origin feedback and refusal of unconsented provider subprocesses.
